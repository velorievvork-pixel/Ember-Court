# Ember Court — план развития

План на ближайшие 3 месяца: новые услуги, продвижение сайта и собственный продукт (автоматическая нарезка подкастов в Reels).

---

## 1. Позиционирование

**Кто мы:** аутсорс-агентство для B2B-команд на раннем этапе роста. Забираем всё, что происходит *до* разговора с клиентом: поиск клиентов, сайт, видео, соцсети.

**Кому продаём:** основателям небольших компаний и стартапов, у которых есть продукт, но нет времени и людей на продажи и маркетинг.

**Главный аргумент:** «Мы привели клиентов себе тем же методом, которым приведём их вам» — поэтому своё продвижение делаем через собственный outbound и превращаем его в кейс.

- **Владелец:** общение с клиентом, приём заказа, оплата, финальная проверка, отправка результата.
- **Claude:** основная работа по заказу (код, тексты, аудит, исследование) в сессии, которую запускает владелец, или по расписанию.
- **Автоматика:** то, что построено один раз (боты, пайплайн монтажа), работает само 24/7.

## 3. Аудит сайта — подробно

### Что проверяем
| Блок | Вопрос |
|---|---|
| Техника и скорость | Быстро ли грузится, корректно ли работает на телефоне |
| SEO | Найдут ли сайт в Google/Яндексе: заголовки, описания, индексация, sitemap |
| Оффер и тексты | Понятно ли за 5 секунд, что предлагают, кому и почему здесь |
| Конверсия | Легко ли оставить заявку: кнопки, формы, контакты |
| Доверие | Кейсы, отзывы, реквизиты, домен, почта на домене |
| Превью в соцсетях | Как выглядит ссылка в Telegram/WhatsApp/LinkedIn |

### Формат результата
Отчёт на 15–40 пунктов. Каждый пункт: проблема → почему это теряет клиентов → как исправить → приоритет (🔴 срочно / 🟡 желательно / 🟢 хорошо).
В конце — предложение исправить всё силами Ember Court.

### Тарифы (ориентир)
| Тариф | Состав | Цена |
|---|---|---|
| Экспресс | 5–7 главных проблем, 1 страница | бесплатно — как повод для outbound |
| Стандарт | Полный отчёт по всем блокам | $50–100 / 5 000–10 000 ₽ |
| Аудит + план | Отчёт + пошаговый план исправлений и смета | $120–200 / 12 000–20 000 ₽ |

### Использование в outbound
Шаблон касания: «Сделали короткий разбор вашего сайта — вот 3 вещи, из-за которых вы, скорее всего, теряете заявки. Полный разбор и исправление можем взять на себя».
Конкретная польза в первом сообщении → заметно выше доля ответов, чем у обычного холодного письма.

## 5. Продвижение

### Каналы (по приоритету)
1. **Собственный outbound.** Одна ниша (например, B2B SaaS / IT-стартапы на ранней стадии). 50–100 компаний в месяц, каждой — персональное сообщение с мини-аудитом сайта.
2. **Площадки фриланса и каталоги.** Upwork, Fiverr (международные), Kwork, FL.ru, Хабр Фриланс (СНГ), Clutch, GoodFirms (каталоги агентств). Первые 3–5 отзывов важнее цены.
3. **Контент-витрина.** Нарезки популярных подкастов в Reels/Shorts/TikTok (с указанием автора) → портфолио + трафик + повод написать автору подкаста.
4. **LinkedIn или Telegram-канал.** 2–3 поста в неделю: разборы холодных писем, мини-аудиты сайтов, закулисье работы.
5. **Партнёрства.** Дизайнеры, разработчики, маркетологи, акселераторы: взаимные рекомендации, 10–20% за приведённого клиента.

### План на 30 дней
| Неделя | Действия |
|---|---|
| 1 | Домен, доработки сайта, аналитика, портфолио видео, шаблон аудита |
| 2 | Профили на площадках, первые 50 касаний с мини-аудитом |
| 3 | Ещё 50 касаний, 3 поста/ролика, 2–3 партнёра |
| 4 | Разбор цифр по каналам → удвоить то, что дало ответы |

### Метрики
| Метрика | Цель на первый месяц |
|---|---|
| Касаний outbound | 100 |
| Доля ответов | 8–15% |
| Созвонов | 3–10 |
| Новых клиентов | 1–3 |
| Отзывов на площадках | 3–5 |

## 6. Продукт: автоматическая нарезка подкастов в Reels

### Что делает
Клиент присылает подкаст (и по желанию референс-ролик «хочу так») → получает 5–15 вертикальных клипов по 30–60 секунд с динамичными субтитрами, зумами и хуком в начале.

### Как устроено
| Шаг | Инструмент |
|---|---|
| Транскрипция с таймингом слов | Whisper / WhisperX |
| Поиск лучших моментов, хуки, заголовки | LLM (Claude API или локальная модель) |
| Кадрирование 9:16 по лицу | MediaPipe |
| Кто сейчас говорит | pyannote + детекция лиц |
| Субтитры с подсветкой слов | ASS-субтитры + ffmpeg |
| Стиль по референсу (темп, цвет, субтитры) | анализатор + библиотека стилей |
| Сборка | ffmpeg |

### Этапы
| Этап | Результат | Срок |
|---|---|---|
| Прототип | Подкаст → вертикальные клипы с субтитрами | 1 неделя |
| MVP | + отслеживание говорящего, 5–10 стилей субтитров, зумы, Telegram-бот с подпиской (Telegram Stars) | 3–4 недели |
| Уровень Opus Clip | + стиль по референсу клиента, оценка «вирусности», B-roll, самопроверка | 2–3 месяца |
| Android-приложение | Клиент к тому же серверу, оплата через Google Play Billing | +3–5 недель (+14 дней закрытого теста на 12 тестировщиков) |

### Расходы
| Статья | Сумма |
|---|---|
| VPS для MVP | $10–40/мес |
| GPU-сервер при росте | $100–300/мес |
| Claude API | ~$0,05–0,30 за часовой подкаст |
| Аккаунт Google Play | $25 разово |

### Отличие от конкурентов (Opus Clip, Vizard, Klap, Submagic)
Русский язык, работа прямо в Telegram, монтаж «как в моём референсе», цена для СНГ.

### Риски
- Качество выбора моментов решает всё — тюнить на реальных подкастах.
- Рендер часового подкаста 5–15 минут — нужна очередь задач.
- Сильные конкуренты — держаться своей ниши и языка.
