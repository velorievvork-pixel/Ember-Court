# Оплата через Stripe — как устроено и как включить

Код готов и лежит в `main`. Кнопки «Оплатить картой» появятся на сайте, только когда в Vercel заданы
`PAYMENTS_ENABLED=1` и ключ Stripe, и сайт пересобран. 10.10 оплату выключили до готовности боевого
аккаунта (американский аккаунт родственника владельца); песочница проверена: оплата и подписка открываются.

## Что сделано

| Часть | Файл | Что делает |
|---|---|---|
| Каталог | `src/lib/stripe.ts` | Что можно купить на сайте: пилот $250 (разовый платёж) и поток $490/мес (подписка). Цены живут в Stripe под ключами `ec_pilot_2w`, `ec_flow_monthly`. |
| Кнопки | `src/components/PayButton.tsx` | Обычная форма без JS. Стоят на странице пилота (пилот и поток) и в блоке цен на главной (пилот). |
| Оплата | `src/app/api/checkout/route.ts` | Создаёт Checkout Session и отправляет на страницу оплаты Stripe. Собирает адрес и налоговый номер компании, создаёт счёт (invoice) на разовый платёж. Если Stripe недоступен — ведёт в Telegram. |
| Уведомления | `src/app/api/stripe/webhook/route.ts` | Проверяет подпись Stripe и пишет владельцу в Telegram: оплата получена, оплата не прошла, продление, отказ от подписки, спор по платежу. Работа начинается по этому сообщению, а не по странице «спасибо». |
| Страница после оплаты | `src/app/[lang]/paid/page.tsx` → `/paid.html` | «Оплата получена», ссылка на анкету, ссылка на управление подпиской (если задана). Не индексируется. |
| Создание цен | `scripts/stripe-catalog.mjs` | Один раз создаёт продукты и цены в Stripe. Можно запускать повторно. |

Работа с ценой «от $…» (сайт, бот, видео и т. д.) на сайте не продаётся: после расчёта выставляется
счёт в Stripe (Dashboard → Invoices → Create). Клиент платит по ссылке из письма, уведомление придёт в Telegram.

## Включение — по шагам

1. **Аккаунт Stripe.** На кого он открыт, решает владелец (см. разговор про LLC знакомого). В настройках:
   публичное имя и statement descriptor `EMBER COURT`, сайт `https://ember-court.vercel.app`.
   До запуска на сайте нужны страницы: условия оказания услуг, возврат (наша гарантия), контакты и
   строка в подвале с юрлицом — без них Stripe может не одобрить аккаунт.
2. **Сначала песочница.** Dashboard → Sandboxes → создать. Всё ниже сначала делается в ней.
3. **Ключ с ограниченными правами (restricted key, `rk_…`)** для сайта: Checkout Sessions — Write,
   Prices — Read. Больше ничего. Секретный ключ `sk_…` на сайт не ставить.
4. **Цены.** На своём компьютере, с временным ключом, у которого есть Products — Write и Prices — Write:
   `STRIPE_SECRET_KEY=rk_test_… node scripts/stripe-catalog.mjs`. Ключ только в команде, не в файлах.
5. **Вебхук.** Dashboard → Developers → Webhooks → Add endpoint:
   `https://ember-court.vercel.app/api/stripe/webhook`, события:
   `checkout.session.completed`, `checkout.session.async_payment_succeeded`,
   `checkout.session.async_payment_failed`, `invoice.paid`, `invoice.payment_failed`,
   `customer.subscription.updated`, `customer.subscription.deleted`, `charge.dispute.created`.
   Скопировать signing secret (`whsec_…`).
6. **Vercel → Settings → Environment Variables**, тип *Sensitive*:
   `STRIPE_SECRET_KEY` (ключ из п. 3), `STRIPE_WEBHOOK_SECRET` (из п. 5).
   И обычную переменную `PAYMENTS_ENABLED` = `1` — это выключатель оплаты на сайте (удалить — кнопки исчезнут).
   По желанию `NEXT_PUBLIC_STRIPE_PORTAL_URL` — ссылка входа в портал клиента (п. 7).
   Затем Redeploy: кнопки появляются при сборке.
7. **Настройки в Dashboard:**
   - Payment methods: карты, Apple Pay, Google Pay, Link (список методов Stripe выбирает сам по этим настройкам).
   - Adaptive Pricing: покупатель видит цену в своей валюте, если Stripe её поддерживает.
   - Emails: квитанции об успешной оплате и письма с оплаченными счетами.
   - Customer portal: включить, взять «login link» для п. 6 — клиент сам отменит подписку или сменит карту.
   - Subscriptions → Smart Retries: Stripe сам повторяет неудачные списания.
8. **Проверка в песочнице.** Карта `4242 4242 4242 4242`, любой срок и CVC — оплата проходит;
   `4000 0025 0000 3155` — с подтверждением 3-D Secure; `4000 0000 0000 9995` — отказ банка.
   Неудачное продление подписки: создать подписку через test clock, сменить карту на
   `4000 0000 0000 0341` и перевести часы на месяц вперёд. В Telegram должны прийти сообщения с пометкой
   «(тестовый режим)».
9. **Запуск.** Повторить п. 3–6 с live-ключами, пройти [Go-live checklist](https://docs.stripe.com/get-started/checklist/go-live).

## Налоги

Stripe Tax не включён: налог он считает, только если у продавца есть регистрация в нужной стране,
иначе молча не считает ничего. Нужен ли он для LLC, продающей услуги за пределы США, — вопрос к
бухгалтеру владельца аккаунта. Для казахстанских ТОО помнить про удержание 20 % КПН, если LLC
зарегистрирована в штате из казахстанского списка льготных юрисдикций (Вайоминг, Делавэр).

## Безопасность

- Ключи только в переменных Vercel (Sensitive), никогда в коде, чате или `.env` в репозитории.
- Сайт получает ключ `rk_…` с двумя правами; если он утечёт — Dashboard → API keys → Roll.
- Вебхук без верной подписи отвечает 400 и ничего не делает.
- Оплата проходит на странице Stripe: сайт по-прежнему не ставит cookies и не грузит скрипты Stripe.
