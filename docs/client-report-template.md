# Отчёт клиенту за неделю — шаблон

Пилот обещает «отчёт по воронке в конце каждой недели». Цифры берутся из `funnel.py`
(репозиторий SaaS, папка клиента), текст — по этому шаблону. Отправлять в пятницу до 17:00
по времени клиента, одним сообщением или письмом. Коротко, без пересказа процесса.

---

**{Компания клиента}: неделя {N} пилота ({даты})**

| | За неделю | С начала |
|---|---|---|
| Нашли компаний с поводом | {n} | {n} |
| Прошли проверку | {n} | {n} |
| Написали | {n} (WhatsApp {n}, почта {n}) | {n} |
| Ответили | {n} | {n} |
| Дошли до первого лица | {n} | {n} |
| Передали вам с интересом | {n} | {n} |

**Кого передали:** {компания — кто — что спросили — когда удобно}. Если никого: «пока никого».

**Что узнали:** одна-две фразы о том, что сработало или нет (канал, повод, страна).
Пример: «В WhatsApp отвечают за час, почта за неделю молчит; на следующей неделе больше WhatsApp».

**Что меняем на следующей неделе:** одна-две фразы.

**Что нужно от вас:** если что-то нужно (ответить лиду, уточнить профиль) — иначе строку убрать.

---

Правила: только цифры из воронки, без округлений «в лучшую сторону»; «ответили» и
«дошли до первого лица» не смешивать; отказ считать ответом, но не интересом.
