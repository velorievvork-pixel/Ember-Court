# Outbound для Ember Court — шаблоны и порядок работы

Шаблоны — каркас, а не текст для копирования. Каждое первое сообщение должно содержать **одно конкретное наблюдение** о компании, которое нельзя было написать, не открыв её сайт. Иначе это спам, и он будет работать как спам.

---

## 1. Кого искать

Одна ниша за раз. Для старта:

| Ниша | Сигнал «им это нужно сейчас» | Что предлагать первым |
|---|---|---|
| B2B SaaS / IT-стартапы, 5–50 человек | Открыта вакансия продажника или маркетолога; недавний раунд; сайт на бесплатном домене | Аудит сайта → outbound |
| Эксперты и компании с подкастом / YouTube | Есть длинные видео, но нет Reels/Shorts или они редкие | 2–3 готовых клипа из их выпуска → нарезка |
| Небольшие производства и услуги | Заявки через форму без ответа; нет мессенджера на сайте | Аудит сайта → бот / автоматизация |

**Проверка перед касанием (2–3 минуты на компанию):** сайт, последние новости, вакансии, соцсети, кто принимает решения. Прогнать экспресс-аудит:

```bash
python3 tools/site-audit/audit.py https://их-сайт.com --express
```

Выбрать из отчёта **1–3 самых понятных** пункта. Не отправлять весь отчёт в первом сообщении.

**Быстрее для списка компаний:** `tools/lead-research` делает это пачкой: находит вакансии в продажах, контакты, проблемы сайта и пишет черновик первого сообщения по правилам ниже.

```bash
python3 tools/lead-research/research.py --input companies.csv -o leads/
```

## 2. Шаблоны

### A. Аудит сайта — Telegram / LinkedIn (коротко)
> {Имя}, добрый день. Смотрел сайт {компания} — {одно живое наблюдение о продукте, не комплимент}.
>
> Заметил пару мест, где сайт, похоже, теряет заявки: {проблема 1 простыми словами} и {проблема 2}. Исправляется за день-два.
>
> Могу прислать короткий разбор — 5–7 пунктов, бесплатно. Прислать?

### B. Аудит сайта — email
**Тема:** {компания}: 3 вещи на сайте, которые стоят вам заявок

> {Имя}, добрый день.
>
> Я из Ember Court, мы помогаем небольшим B2B-командам с поиском клиентов и сайтами. Посмотрел {сайт} перед тем, как писать, — {наблюдение}.
>
> Бросилось в глаза:
> 1. {проблема 1} — {чем это плохо для клиента в одной фразе}.
> 2. {проблема 2} — …
> 3. {проблема 3} — …
>
> Если интересно, пришлю полный разбор с тем, что и в каком порядке исправить. Исправлять необязательно у нас — отчёт подойдёт любому разработчику.
>
> {Подпись} · ember-court.vercel.app

### C. Нарезка для автора подкаста
Сначала сделать 2–3 клипа из их свежего выпуска:
```bash
cd clipper && python -m clipper run выпуск.mp4 -o demo/ --clips 3
```

> {Имя}, привет! Слушал ваш выпуск про {тема} — момент про {конкретная мысль} зацепил.
>
> Нарезал из него 3 коротких ролика под Reels/Shorts с субтитрами — просто посмотреть, как это может выглядеть: {ссылка на папку}.
>
> Если зайдёт — можем делать так с каждым выпуском. Если нет — пусть просто останутся у вас.

### D. Outbound как услуга (после аудита или для команд без продажника)
> {Имя}, добрый день. Видел, что {компания} ищет {роль} — значит, поток клиентов сейчас на вас.
>
> Мы закрываем ровно эту часть: вручную находим компании, у которых есть повод вас выслушать, проверяем каждую и пишем первое сообщение. Вам остаются созвоны с теми, кто ответил.
>
> Могу показать на 10 компаниях из вашей ниши, кого бы мы выбрали и почему — без оплаты. Интересно?

## 3. Повторные касания
Не больше двух, каждое — с новой пользой, а не «напоминаю о себе».

| Когда | Что написать |
|---|---|
| +3–4 дня | Одна новая находка: «Ещё заметил: {проблема} — это самое простое из исправлений». |
| +7–10 дней | Закрыть вежливо: «Не буду больше беспокоить. Если захотите разбор — просто ответьте на это сообщение». |

## 4. Учёт
Таблица, по строке на компанию:

| Компания | Сайт | ЛПР | Канал | Сигнал | Наблюдение | Дата 1 | Дата 2 | Дата 3 | Ответ | Итог |
|---|---|---|---|---|---|---|---|---|---|---|

Каждую пятницу считать: касания → ответы → созвоны → сделки, отдельно по каждому шаблону и каналу. Через 2 недели оставить лучший вариант и удвоить объём по нему.

**Цель первого месяца:** 100 касаний → 8–15 ответов → 3–10 созвонов → 1–3 клиента.
