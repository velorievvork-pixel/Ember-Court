# Исследование лидов для outbound

На вход список сайтов компаний, на выходе карточка по каждой: сигналы интереса, контакты, проблемы сайта, какую услугу предлагать и черновик первого сообщения.

```bash
# несколько сайтов
python3 tools/lead-research/research.py https://a.com https://b.com -o leads/

# из таблицы (колонка url / site / website / сайт) или текстового файла
python3 tools/lead-research/research.py --input companies.csv -o leads/

# черновики пишет Claude по правилам из docs/outbound.md (нужен ANTHROPIC_API_KEY)
python3 tools/lead-research/research.py --input companies.csv -o leads/ --claude
```

Результат: `leads/leads.csv` (одна строка на компанию, отсортировано по оценке) и `leads/<домен>.md` с карточкой.

## Что проверяется
| Что | Как | Баллы |
|---|---|---|
| Вакансии в продажах и маркетинге | ищет страницу вакансий, читает названия ролей | +4 |
| Слова о росте | «расширяемся», «раунд», «we're hiring», «launched»… | +2 |
| Нет способа связаться | ни формы, ни мессенджера, ни почты | +1 |
| Серьёзные проблемы сайта | модуль `tools/site-audit` | +1 |

Также собираются почты, телефоны, Telegram, WhatsApp, LinkedIn, Instagram и ссылки на страницы вакансий, о компании и контактов.

## Какую услугу предлагать
- **outbound**, если компания нанимает в продажи: черновик начинается с этой вакансии.
- **audit**, если у сайта есть проблема, понятная владельцу бизнеса: закрыт от поиска, бесплатный домен, нет способа связаться, нет мобильной версии, медленный, не видно цен, пустое превью ссылки. Технические мелочи (редиректы, вес HTML, schema.org) поводом не считаются.
- Если конкретного повода нет, **черновик не пишется**. Выдуманный повод в первом сообщении губит лид, поэтому повод ищется вручную или с `--claude`.

Черновики пишутся на языке сайта: русский, английский или украинский.

## Перед отправкой
Инструмент готовит, а отправляет человек. В каждой карточке есть чек-лист: имя ЛПР, актуальность сигнала, не холдинг ли это и не наш ли это клиент.
