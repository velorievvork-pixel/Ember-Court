# Аудит сайта

Скрипт проверяет сайт так, как его видят новый клиент и поисковик, и пишет отчёт в Markdown на русском: 🔴 срочно / 🟡 желательно / 🟢 в порядке.

Нужен только Python 3.9+, без установки пакетов.

```bash
# Бесплатный экспресс-разбор (7 главных проблем) — для outbound и первого касания
python3 tools/site-audit/audit.py https://example.com --express

# Полный отчёт в файл — платный «Полный разбор»
python3 tools/site-audit/audit.py https://example.com -o example-audit.md
```

## Что проверяется
- **Техника:** HTTPS и редирект с http, скорость ответа, вес HTML, блокирующие скрипты, смешанный контент, битые внутренние ссылки.
- **Мобильная версия:** meta viewport, ответ сервера для мобильного браузера.
- **SEO:** title, description, H1, язык страницы, canonical, noindex, robots.txt, sitemap.xml, schema.org, alt у картинок.
- **Тексты:** объём текста, видны ли цены.
- **Конверсия:** кликабельные контакты (телефон, почта, Telegram, WhatsApp), формы и число полей.
- **Доверие:** бесплатный домен, отзывы/кейсы, favicon.
- **Соцсети:** Open Graph (превью ссылки).
- **Аналитика:** Google Analytics, Яндекс Метрика, Vercel Analytics, Plausible, Meta Pixel.

## Как использовать в работе
1. Прогнать скрипт.
2. Пройти блок «Что проверить вручную» в конце отчёта: первый экран, оффер, вид на телефоне. Автоматика этого не видит.
3. Дописать 1–3 наблюдения своими словами — именно они делают разбор ценным.
4. Экспресс-версию отправить в первом сообщении outbound, полную — после оплаты.
