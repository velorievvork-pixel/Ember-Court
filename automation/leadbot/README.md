# Бот для заявок (шаблон услуги «Автоматизация и боты»)

Один бот на клиента. Заявки приходят из двух мест, и оба канала ведут в одни и те же точки доставки.

**Откуда приходят заявки**
- **Telegram:** человек пишет боту, тот задаёт вопросы по шагам: услуга → имя → телефон кнопкой или любой контакт → задача (можно пропустить) → проверка → «Отправить». Команда `/faq` и кнопка в меню показывают частые вопросы.
- **Форма на сайте:** сайт отправляет `POST /lead`, бот доставляет заявку так же, как из Telegram.

**Куда уходит заявка**
- Сообщение в Telegram владельцу (одному или нескольким). Оно отправляется первым: даже если таблица или CRM недоступны, человек заявку увидит.
- CSV-файл.
- Google Таблица через Apps Script.
- Любая CRM, которая принимает вебхук с JSON.

Тексты, услуги и FAQ меняются в `config.yaml` без правки кода.

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. `cp .env.example .env`. Впишите `BOT_TOKEN`, Telegram ID владельцев в `OWNER_CHAT_IDS` (свой ID подскажет @userinfobot) и `LEAD_TOKEN`, если нужна форма на сайте.
3. `cp config.example.yaml config.yaml` и поменяйте название, тексты, услуги, FAQ и точки доставки.
4. Запуск:
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m leadbot
```
Бот работает через long polling, поэтому белый IP и домен ему не нужны. Домен и HTTPS нужны только для формы на сайте (см. ниже).

## Поведение
| Ситуация | Что делает бот |
|---|---|
| Человек пишет «Здравствуйте» вместо `/start` | Сразу начинает анкету |
| Вместо кнопки услуги написан текст | Текст записывается как услуга |
| Двойное нажатие «Отправить» | Заявка уходит один раз |
| В течение 10 минут после заявки человек дописывает что-то ещё | Текст уходит владельцу как «Дополнение к заявке» |
| «Заполнить заново» | Ответы стираются, анкета начинается сначала |
| Поле длиннее 500 символов | Обрезается |

## Форма на сайте
Сайт отправляет JSON или обычную форму на `https://<адрес бота>/lead` с заголовком `X-Lead-Token`.

**Поля**

| Поле | Обязательное | Что в нём |
|---|---|---|
| `contact`, `phone` или `email` | да, хотя бы одно | контакт человека |
| `name` | нет | имя |
| `service` | нет | услуга |
| `comment` или `message` | нет | текст заявки |
| `page` | нет | страница, с которой отправлена форма |

**Ответы сервера**

| Код | Когда |
|---|---|
| `200` | Заявка принята |
| `403` | Неверный токен |
| `413` | Слишком большой запрос |
| `422` | Нет контакта |
| `429` | Больше 5 заявок с одного IP за 10 минут |
| `502` | Заявка не доставлена ни в одну точку. Сайт должен показать ошибку и предложить написать в мессенджер. |

```html
<form id="lead">
  <input name="name" placeholder="Имя">
  <input name="phone" placeholder="Телефон" required>
  <textarea name="comment" placeholder="Задача"></textarea>
  <!-- ловушка для ботов: людям не видна, поэтому остаётся пустой -->
  <input name="website" tabindex="-1" autocomplete="off" style="position:absolute;left:-9999px">
  <button>Отправить</button>
</form>
<script>
document.getElementById('lead').addEventListener('submit', async (e) => {
  e.preventDefault();
  const data = Object.fromEntries(new FormData(e.target));
  data.page = location.href;
  const r = await fetch('https://bot.example.com/lead', {
    method: 'POST',
    headers: {'Content-Type': 'application/json', 'X-Lead-Token': 'ВАШ_LEAD_TOKEN'},
    body: JSON.stringify(data),
  });
  e.target.innerHTML = r.ok ? 'Спасибо! Заявка принята.' : 'Не отправилось. Напишите нам в Telegram.';
});
</script>
```

**Защита от спама**
- Токен виден в коде страницы, поэтому он отсекает только случайные сканеры.
- От спама защищают:
  - скрытое поле-ловушка `website`: бот отвечает «принято», но заявку никуда не отправляет;
  - лимит 5 заявок с одного IP за 10 минут;
  - предел 500 символов на поле;
  - предел 16 КБ на весь запрос.
- В `web.allowed_origin` укажите адрес сайта вместо `*`.
- **Если бот стоит за nginx или Caddy:** включите `web.trust_proxy: true`, иначе у всех заявок будет IP прокси и лимит сработает на всех сразу.
- **Если прокси нет:** `trust_proxy` не включайте. Иначе заголовок `X-Forwarded-For` можно подделать и обойти лимит.

**HTTPS**
Сайт на HTTPS не может отправлять запросы на HTTP, поэтому бот должен быть доступен по HTTPS. Проще всего поставить перед ним Caddy (`bot.example.com { reverse_proxy localhost:8080 }`), он сам выпустит сертификат.

## Google Таблица
1. Откройте таблицу, выберите «Расширения» → «Apps Script» и вставьте код:
```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSheet().appendRow(
    [d.created_at, d.source, d.name, d.contact, d.service, d.comment, d.tg_user, d.page]);
  return ContentService.createTextOutput('ok');
}
```
2. Выберите «Развернуть» → «Новое развёртывание» → «Веб-приложение», доступ «Все».
3. Вставьте полученный URL в `sinks.google_sheets_webhook`.

## CSV
Если значение начинается с `=`, `+`, `-` или `@`, перед ним ставится апостроф. Иначе Excel и Google Таблицы выполнили бы его как формулу: любой посетитель сайта мог бы вписать в заявку `=HYPERLINK(...)`. По той же причине телефон в CSV выглядит как `'+7…`.

## Тесты
```bash
python3 -m unittest discover tests
```
Тесты проходят без Telegram и без сети. Анкета проверяется целиком через диспетчер aiogram с подменённым Bot API. Форма сайта проверяется на локальном сервере: токен, ловушка, лимит, размер запроса, CORS.
