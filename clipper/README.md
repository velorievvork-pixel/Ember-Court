# Clipper — нарезка подкастов в Reels / Shorts

Длинное видео (подкаст, интервью, вебинар) превращается в готовые вертикальные клипы 1080×1920:
- **лучшие моменты** находятся автоматически: локальной оценкой (бесплатно, без интернета) или через Claude;
- **кадр 9:16 следует за лицом** говорящего; при смене говорящего кадр переключается мгновенно, как у монтажёра;
- **субтитры по 2–3 слова**, произносимое слово подсвечено и «выпрыгивает»;
- **хук-заголовок** на первые 2,5 секунды;
- **зумы** в ритме референса, **цвет** под референс, громкость выровнена под соцсети (−14 LUFS).

## Установка
```bash
cd clipper
pip install -r requirements.txt
```
Нужен Python 3.9+. ffmpeg берётся системный, если он есть, иначе из пакета `imageio-ffmpeg`.
При первом запуске скачиваются модель распознавания речи Whisper и детектор лиц YuNet (230 КБ).

## Запуск
```bash
# 5 клипов по 20–60 секунд, стиль bold
python -m clipper run podcast.mp4 -o out/

# стиль «как в этом ролике»: темп, цвет и длина берутся с референса
python -m clipper run podcast.mp4 -o out/ --reference reference.mp4 --style minimal

# посмотреть, что система «прочитала» из референса
python -m clipper analyze reference.mp4
```

В папке `out/` появятся `clip_01.mp4`, `clip_02.mp4`… и описание `clips.md` / `clips.json`: время, заголовок, хук, текст каждого клипа.

### Основные параметры
| Параметр | Что делает |
|---|---|
| `--clips 5` | сколько клипов нарезать |
| `--min 20 --max 60` | допустимая длина клипа в секундах |
| `--style bold` | `bold` (жёлтая подсветка, КАПС), `minimal` (спокойный, для B2B), `hype` (TikTok), или путь к своему `.yaml` |
| `--reference ref.mp4` | подстроить темп зумов, цвет и длину под референс |
| `--selector auto` | `claude` — выбор моментов через Claude, `local` — без API; `auto` берёт Claude, если задан `ANTHROPIC_API_KEY` |
| `--whisper small` | качество распознавания: `tiny` (быстро) … `large-v3` (точно, нужна видеокарта) |
| `--lang ru` | язык речи, если автоопределение ошибается |

## Выбор моментов
- **Локально (бесплатно):** оценивает окна из целых предложений по хуку в начале (вопрос, сильные слова), темпу речи, громкости относительно всего эпизода, паузам внутри и законченности мысли.
- **Claude (`ANTHROPIC_API_KEY`):** модель читает весь транскрипт и выбирает законченные мысли с сильным началом, пишет заголовок и хук на языке подкаста. Около $0,05–0,30 за час подкаста. Модель можно сменить через `CLIPPER_MODEL`. При ошибке или отказе автоматически включается локальный выбор.

## Свой стиль
Скопируйте `clipper/styles/bold.yaml`, поменяйте цвета, размер, число слов в строке, частоту зумов и передайте путь в `--style`.
Свои шрифты (`.ttf`/`.otf`) кладите в `clipper/fonts/` и указывайте имя шрифта в `captions.font`.
