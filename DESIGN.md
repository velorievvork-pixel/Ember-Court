# Ember Court: дизайн-система

Используется при генерации в Google Stitch (читает этот файл как дизайн-систему) и как контракт для кода в `src/`.

## Design Read
Тёмный, «освещённый углями» сайт B2B-аутсорс-агентства для основателей на ранней стадии. Тон: сдержанный, точный, честный («точность вместо объёма»). Режим: **Redesign / Preserve**. Бренд, структура страниц, адреса и голос текста сохраняются, стек и типографика обновляются.

## Dials (Taste Skill)
| Dial | Значение | Почему |
|---|---|---|
| DESIGN_VARIANCE | 7 | Асимметричный первый экран и bento-сетка услуг, но без экспериментов, которые мешают B2B-доверию |
| MOTION_INTENSITY | 6 | Живой огонь в первом экране, мягкое появление секций, отклик кнопок. Без scroll-hijack |
| VISUAL_DENSITY | 4 | Много воздуха: продаём внимание к деталям, а не объём |

## Цвет
Одна тёмная тема на весь сайт: огонь читается только на тёмном фоне. Светлой темы нет осознанно.

| Токен | HEX | Роль |
|---|---|---|
| `ground` | `#0B0A09` | фон |
| `ground-deep` | `#060504` | низ страницы, текст на кнопке |
| `panel` | `#12100D` | поднятые блоки |
| `rule` | `#262019` | линии, границы |
| `ink` | `#EDE6DA` | основной текст |
| `ink-soft` | `#A99E8D` | второстепенный текст (AA на `ground`) |
| `ink-faint` | `#8A7F71` | подписи (AA для мелкого текста) |
| `ember` | `#FF9A3D` | **единственный акцент**: CTA, ссылки, выделения |
| `ember-core` | `#FFE3B0` | блик, hover |
| `ember-hot` | `#FF6B35` | только в градиенте угля и эффекте огня |

Запрещено: фиолетовые и синие свечения, неоновые тени, чистый `#000`, второй акцентный цвет. Material-цвета из Stitch (например `#c8a0f0`) вычищать.

## Типографика
| Роль | Шрифт | Правило |
|---|---|---|
| Заголовки и логотип | Cormorant (кириллица) | Фирменный шрифт бренда «Court». Акцент в заголовке через *курсив того же шрифта*, не другой гарнитурой |
| Текст и интерфейс | Geist | Основной текст, кнопки, меню |
| Метки | Geist Mono | Не больше одной метки на 3 секции, без нумерации секций |

Заголовки не больше двух строк на десктопе. Подзаголовок первого экрана не длиннее 20 слов.

## Форма
- Радиус: `2px` для блоков, `999px` только для кнопок-пилюль. Других радиусов нет.
- Карточки только там, где нужна иерархия. В остальных случаях группировка отступами и `border-t`.
- Иконки: Phosphor (`@phosphor-icons/react`), толщина `light`. Самодельные SVG-иконки запрещены. Исключение: знак-уголь, это логотип.

## Движение
- Огонь (WebGL, `blaze.js`) только в первом экране. Уважает `prefers-reduced-motion` и останавливается вне экрана.
- Появление секций: `opacity` + `translateY 16px`, 0.6 с, один раз. Задержка между элементами 60 мс.
- Кнопки: магнитный сдвиг до 6 px через `useMotionValue`, без `useState`.
- Lenis для плавной прокрутки. GSAP не используется: Motion уже покрывает задачи, а две библиотеки конфликтуют за кадры.
- Анимируются только `transform` и `opacity`.

## Тексты
- Голос: короткие предложения, конкретика, без «инновационных решений».
- EN: без длинных тире. RU/UK: тире только там, где его требует грамматика (подлежащее и сказуемое), в кнопках, меню и метках тире нет.
- Диапазоны через дефис: `5-7`, `30-150`.
- Один CTA на одно намерение: «Написать» (разговор) и «Бесплатный аудит сайта» (проверка). Других CTA нет.
